## Flashing procedure

Both sides must be flashed separately.

Right side:

1. Hold the top right button
2. connect the right side of the keyboard to USB.
3. run `qmk flash -bl uf2-split-right`

Left side:

1. Hold the top left button
2. connect the left side of the keyboard to USB.
3. run `qmk flash -bl uf2-split-left`
